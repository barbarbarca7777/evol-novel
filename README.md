# EVOL -エヴォル- 制作プロジェクト

学園バトル×能力者もの(ジャンプ路線)に、エヴァンゲリオンの世界観・キャラクターを翻案した小説プロジェクト。

## 構成

```
settings/            設定の一元管理(ここを編集する)
  characters.psd1     キャラクター設定
  world.psd1          組織名・地名・パワーシステムなどの世界観設定
  relationships.psd1   キャラ同士の呼び方(参照用。自動置換の対象外)
  timeline.psd1        入学・転入などの時系列(参照用。自動置換の対象外)
  powersystem.psd1     使徒のコア弱点ルール・技体系・能力成長段階(参照用。自動置換の対象外)
  factions.psd1        組織間の対立構造マップ(参照用。自動置換の対象外)
  .snapshot/           自動生成。前回同期時の設定のバックアップ(触らなくてよい)
manuscript/           本文(章ごとに .md ファイル)
notes/
  synopses.md          各話のあらすじ台帳(100〜200字/話)
  foreshadowing_ledger.md  伏線台帳
  episode01_meeting.md    会議ログ(話ごとに残す)
scripts/
  Sync-Settings.ps1    設定変更を検知して本文へ自動反映するツール
```

## 使い方

1. `settings\characters.psd1` や `settings\world.psd1` を編集する
   (例: キャラの名前、学園名、組織名、必殺技名などを変更)
2. PowerShellで以下を実行する

   ```powershell
   .\scripts\Sync-Settings.ps1
   ```

   前回実行時から変わった固有名詞を検出し、`manuscript` 内の本文を自動で一括置換する。

3. 常に自動反映させたい場合は監視モードを使う

   ```powershell
   .\scripts\Sync-Settings.ps1 -Watch
   ```

   このターミナルを開いたままにしておくと、設定ファイルを保存するたびに自動で同期される。
   終了するときは Ctrl+C。

4. 実際に置換される前に内容を確認したい場合

   ```powershell
   .\scripts\Sync-Settings.ps1 -WhatIf
   ```

## 自動反映される項目・されない項目

- **自動反映される**: `FullName` / `Nickname` / `EvaName` / `Technique` / `OrgName` / `SchoolName` / `PlaceName` / `ShitoName` / `Title` など、固有名詞にあたるフィールド
- **自動反映されない**:
  - `Personality`(性格) や `Background`(背景設定) のような説明文。機械的な文字列置換になじまないため、変更時は該当する章を手動で見直す(必要ならClaude Codeに書き直させる)
  - `Surname` / `Given` の単体変更。**姓や名だけを変えても本文には反映されない。** 同姓の別キャラがいると誤爆する事故が実際に起きたため、意図的に対象外にしている。名前を変えたいときは必ず `FullName` を書き換えること

## 現在の設定の要点(仮決め・要確認)

- 主人公: 鈴木ジュンペイ(高1・虎杖悠仁/黒崎一護寄りの性格)。**シンジの代役ではなく、既存パイロット勢とは無関係の新規キャラ**。EVAナンバリングに当てはまらない「分類外」の力を持つ
- 既存の第一世代パイロット(物語開始時点で既に実在・実戦経験あり): 碇シンジ(初号)、綾波レイ(零号)、式波アスカ(弐号)
- 契約講師(非担任)兼指揮官: 葛城ミサト
- 謎の転入生: 渚カヲル
- 組織長: 碇ゲンドウ(シンジの父)。ジュンペイとは血縁関係なし
- 登場人物名は一旦、新劇場版(Shin Gekijouban)準拠
- 敵組織: セフィロト機関(SEELE枠) / 表の対使徒機関: 創世機関(NERV枠)
- パワー名称: EVA(乗り物ではなく、適合者が纏う戦闘形態) / 必殺・防御技: ATフィールド(絶対領域)
- 敵役: 使徒(聖書の天使名をコードネームとして使用、一部は途中で仲間になる想定)
- 作品仮題: 『EVOL -エヴォル-』
- 1話のボリューム目安: 約5,000文字
- ネタ出し→執筆のプロセスは [CLAUDE.md](CLAUDE.md) 参照

これらの名称はすべて `settings/` 内の値なので、気に入らなければ書き換えて `Sync-Settings.ps1` を実行するだけで全文に反映される。
