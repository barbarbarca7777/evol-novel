# EVOL -エヴォル- 制作プロジェクト

エヴァンゲリオンのキャラクターを「器」として借用し、ジャンプ系王道バトル漫画の構造で描く学園能力バトル物語プロジェクト。

**2026-08-27、設定のベースを乗り換えた。** 旧設定(創世機関/セフィロト/ゲヘナ体系)は `archive/v1-evol/` に参考資料として保存。新設定の原本資料(添付docxの抽出テキスト)は `notes/source_v2/` を参照。

## 構成

```
settings/            設定の一元管理(ここを編集する)
  characters.psd1     キャラクター設定(主要キャラのみ詳細化。その他は factions.psd1 のロースター参照)
  world.psd1          タイトル・神話体系・世界観・地理設定
  powersystem.psd1     霊格の等級体系・能力5分類・技体系・神話→キャラのマッピング
  factions.psd1        NERV学園(三校)・ゼーレの組織構造
  relationships.psd1   キャラ同士の呼び方・恋愛マップ・寮配置(参照用。自動置換の対象外)
  timeline.psd1        年齢表・年表・全体スケジュール(参照用。自動置換の対象外)
  .snapshot/           自動生成。前回同期時の設定のバックアップ(触らなくてよい)
manuscript/           本文(章ごとに .md ファイル。新設定移行後はまだ空)
notes/
  synopses.md          各話のあらすじ台帳(100〜200字/話)
  foreshadowing_ledger.md  伏線台帳
  arc_roadmap.md        全体ロードマップ(全741話・4部+回想2部+エピローグ2つ)
  source_v2/            新設定の原本資料(添付docxから抽出したテキスト)
archive/v1-evol/       旧設定一式(参考資料。現行設定とは非互換)
scripts/
  Sync-Settings.ps1    設定変更を検知して本文へ自動反映するツール
```

## 使い方

1. `settings\characters.psd1` や `settings\world.psd1` を編集する
   (例: キャラの名前、学園名、組織名、必殺技名などを変更)
2. PowerShellで以下を実行する

   ```powershell
   .\scripts\Sync-Settings.ps1
   ```

   前回実行時から変わった固有名詞を検出し、`manuscript` 内の本文を自動で一括置換する。

3. 常に自動反映させたい場合は監視モードを使う

   ```powershell
   .\scripts\Sync-Settings.ps1 -Watch
   ```

   このターミナルを開いたままにしておくと、設定ファイルを保存するたびに自動で同期される。
   終了するときは Ctrl+C。

4. 実際に置換される前に内容を確認したい場合

   ```powershell
   .\scripts\Sync-Settings.ps1 -WhatIf
   ```

## 自動反映される項目・されない項目

- **自動反映される**: `FullName` / `Nickname` / `EvaName` / `Technique` / `OrgName` / `SchoolName` / `PlaceName` / `ShitoName` / `Title` / `DisplayName` など、固有名詞にあたるフィールド(`characters.psd1` / `world.psd1` / `factions.psd1` が対象)
- **自動反映されない**:
  - `Personality`(性格) や `Background`(背景設定) のような説明文。機械的な文字列置換になじまないため、変更時は該当する章を手動で見直す(必要ならClaude Codeに書き直させる)
  - `Surname` / `Given` の単体変更。**姓や名だけを変えても本文には反映されない。** 同姓の別キャラがいると誤爆する事故が実際に起きたため、意図的に対象外にしている。名前を変えたいときは必ず `FullName` を書き換えること

## 現在の設定の要点(2026-08-27ベース乗り換え後)

- タイトル由来: EVANGELION(福音)+LOGOS(言葉・理)。「神の力なき人間の理が、福音となる」
- 力の正体: 「霊格」。神話上の神格を宿すことで発現する能力(乗り物ではない)。等級は呪術廻戦型の統一7段階(特級〜伍級)
- 主人公: 鈴木ジュンペイ(霊格ゼロ・五門。性格モデルは虎杖悠仁)。もう一人の主人公格: 碇シンジ(測定不能・分類外。性格モデルは乙骨憂太)
- ヒロイン: 式波アスカ・ラングレー(ブリュンヒルデ)、綾波レイ(ツクヨミ)
- 舞台: NERV学園(本校・京都校・欧州校の三校体制)。隠れ蓑ではなく公然と存在する養成機関(ヒロアカ雄英モデル)
- 敵対組織: ゼーレ(三層構造: オリンポス十二席/グリゴリの器/タルタロス)
- 謎の存在: 渚カヲル(ルシファーの依代。ジュンペイの力の源だが本編読者には第1.5部まで伏せる)
- 全体構成: 全4部+回想2部+エピローグ2つ、全約741話。詳細は [notes/arc_roadmap.md](notes/arc_roadmap.md)
- 1話のボリューム目安: 約5,000文字
- ネタ出し→執筆のプロセスは [CLAUDE.md](CLAUDE.md) 参照

これらの名称はすべて `settings/` 内の値なので、気に入らなければ書き換えて `Sync-Settings.ps1` を実行するだけで全文に反映される。
